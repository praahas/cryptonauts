RAIL FENCE CIPHER

MISSION 03 // REARRANGE, DON'T REPLACE

BRIEFING.TXT

The story

So far, every cipher we've looked at has substituted letters: A becomes D, B becomes E, etc. But there's a completely different approach: instead of replacing letters, rearrange them.

The Rail Fence cipher (also called the Zigzag cipher) is one of the oldest and simplest transposition ciphers. Here's how it works:

Imagine writing your message in a zigzag pattern across two (or three, or four) parallel "rails" like a fence. Let's say we want to encrypt "HELLO WORLD" with 2 rails:

H O O L
E L W R D

Now read off the rails in order: HOOLLELLWRD. That's the ciphertext.

With 3 rails, the pattern gets more interesting, creating a different zigzag. Each additional rail makes the pattern more complex.

Why this matters

Rail Fence teaches a huge concept: transposition ciphers don't change the letters, only their positions. This means frequency analysis (counting which letters appear most often) still works — the letter frequencies don't change. But it does protect against a casual observer: the message structure is scrambled.

Rail Fence itself is trivial to break if you know the number of rails, but it's the ancestor of much more sophisticated transposition ciphers, and the principle — rearrange instead of replace — is still used in modern cryptography.

KEY INSIGHT
Modern ciphers often use both substitution and transposition. The more operations you stack, the harder it is to break. A cipher that substitutes AND then rearranges is much stronger than either one alone.

The algorithm

Encryption:

  1. Write plaintext in a zigzag pattern across N rails
  2. Read rails top to bottom, left to right

Decryption:

  1. Figure out how many characters go in each rail (the zigzag lengths differ)
  2. Fill the rails with ciphertext in order
  3. Read off the zigzag pattern to recover plaintext

For N rails and a message of length L:

Period of zigzag = 2 * (N - 1)

Number of complete cycles = L / Period

Remaining characters fill the last partial cycle

Example (2 rails, "HELLO"):

H L → Rail 0: HLO

E O → Rail 1: EL

Ciphertext: HLO + EL = HLOEL
